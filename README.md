# Through the Stars

A small browser game for practising straight-line graphs (y = mx + c).
Type the equation of a line so it passes through every star and misses every mine.

- 24 levels in 5 chapters: from y = x, through gradient and intercept, up to puzzles that need two or three lines
- Works on phones with a built-in keypad
- No build step: open `index.html` or turn on GitHub Pages
